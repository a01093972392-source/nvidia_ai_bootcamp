# [최종 프로젝트] AI SHIFT LAB 탈출

당신은 오래전에 폐쇄된 듯한 AI SHIFT LAB에 갇혔습니다.
연구소를 탐색하고 탈출하세요.

AI에게 **자연어로 말하면** AI가 게임 도구를 골라 실행합니다.
그런데 AI는 암호 해독, 날짜·수 계산 같은 **정확해야 하는 일을 못 합니다.**
그럴 때 필요한 기능을 `my_tools.py`에 직접 만들어 AI에게 쥐여주세요. 그게 이 과제입니다.

## 시작하기

**1. 설치** (Python 3.12 권장)

```bash
pip install -r requirements.txt
```

> Python 3.15 같은 아주 새 버전에서는 `pyyaml` 빌드 오류로 설치가 실패할 수 있습니다.
> 그때는 Python 3.12로 가상환경을 만들어 쓰세요: `py -3.12 -m venv .venv`

**2. 키 설정** — `.env.example`을 **`.env`로 복사**한 뒤 본인 키를 채웁니다.

```
OPENAI_API_KEY=sk-여기에-본인-키
```

`.env`는 절대 공유하거나 커밋하지 마세요.

**3. 실행** — 둘 중 하나를 고릅니다.

| 버전 | 명령 | 특징 |
|---|---|---|
| 웹 (추천) | `python web_server.py` | 브라우저가 열립니다 (http://127.0.0.1:8765). 방 그림, 문 열림 연출, 소리 |
| 터미널 | `python client.py` | 색상 테마와 문 그림이 나오는 터미널 화면 |

게임이 시작되면 자연어로 말하면 됩니다.

```
> 게임 시작해          ← 시작하면 연구실로 자동 이동합니다
> 연구용 PC 조사해
> 서버실 문 열어
> 힌트 줘
```

## 여러분이 할 일

**`my_tools.py` 하나만 작성합니다.** 나머지 파일은 열지 않아도 됩니다.

```python
@mcp.tool
def 함수이름(인자: 타입) -> 반환타입:
    """이 도구가 무엇을 하는지 한 줄로 설명합니다."""
    ...
```

- 함수에 **타입**과 **설명(docstring)** 을 적습니다. AI는 이 설명을 읽고 언제 쓸지 판단합니다.
  설명이 부실하면 도구를 만들어도 AI가 쓰지 않거나 엉뚱하게 씁니다.
- 파일을 **저장하면 자동으로 반영**됩니다. 다시 실행할 필요가 없습니다.
  - 웹: 1초 안에 오른쪽 `MY TOOLS` 목록이 바뀝니다.
  - 터미널: 다음 입력부터 새 도구를 씁니다.
  - 저장하다 문법 오류가 나도 게임은 **이전 도구로 계속**되고, 화면에 경고만 표시됩니다. 고쳐서 저장하면 자동 복구됩니다.

## AI가 지키는 규칙 (코드로 강제됩니다)

게임 서버 호출은 모두 `engine.py`를 거칩니다. 아래 규칙은 AI에게 부탁하는 것이 아니라 코드가 막고,
막힌 경우 화면에 ⛔ 안내가 나옵니다.

| 규칙 | 어떻게 지키나 |
|---|---|
| **퍼즐 풀이·날짜·계산은 도구 없이 AI가 하지 않는다** | 정답 제출(`submit_answer`)은 ① 사용자가 말한 값 ② 내 도구가 계산한 값 ③ 화면에 적힌 값일 때만 통과합니다. 요일·며칠·합계·평균처럼 계산이 필요한 요청에 도구 없이 AI가 직접 낸 답은 버립니다. 시스템 프롬프트에도 같은 금지가 들어 있습니다. |
| **힌트는 요청할 때만** | 힌트(`interact`의 `hint`)는 그 턴의 메시지에 "힌트", "막혔어", "도와줘" 등이 있을 때만 실행됩니다. 한 번 요청했다고 다음 턴으로 이어지지 않습니다. |
| **이동하면 자동으로 장소 갱신** | 게임을 시작하거나 문을 열고 이동하면 `observe`가 자동으로 불려 "주변 둘러봐"를 말하지 않아도 새 장소가 나옵니다. 조사·정답 제출이 성공할 때마다 장소를 조용히 다시 읽어, 새로 생긴 문이나 물체도 바로 반영됩니다. |
| **세션은 시스템이 관리** | `session_id`는 AI에게 숨기고 자동으로 붙입니다. AI가 값을 잘못 베끼는 일이 없습니다. |

> 한계: 요청이 계산인지 판단하는 일부는 키워드 기반입니다. "그럼 내일은?"처럼 계산 단어가 없는 질문은
> 통과할 수 있습니다. 정답 제출은 값의 출처로 확인하므로 이 경우에도 확실히 막힙니다.

## 막혔을 때

- **`힌트 줘`** — 막힌 대상에 대해 두 단계까지 힌트를 받습니다 (요청해야만 나옵니다)
- **`상태 알려줘`** — 지금까지 찾은 단서와 진행 상황을 다시 봅니다

## 웹 화면 읽는 법

| 영역 | 내용 |
|---|---|
| 위쪽 그림 | 지금 있는 장소. 연구실, 서버실, 보안 통제실, 그 밖의 장소(복도), 탈출 장면 |
| 큰 문 | 나갈 수 있는 곳. 앞으로 가는 문은 오른쪽, 이미 가 본 방으로 돌아가는 문은 왼쪽 |
| 아이콘 | 조사할 수 있는 물체. 이름에 맞는 그림(서버 랙, 단말, 패널, 케이블, 금고, 메모 …)으로 나오고, 모르는 이름은 `?` 상자 |
| TERMINAL | 대화 기록. `⚙`는 AI가 고른 도구, 보라색 상자는 내 도구 결과, 노란 상자는 ⛔ 차단 안내 |
| 오른쪽 `이 장소에서` | 서버가 알려준 오브젝트와 출구 목록. 읽지 못한 줄은 `⚠ 읽지 못한 줄`로 표시 |
| 오른쪽 `MY TOOLS` | 내 도구 목록 (AI가 쓰면 잠깐 빛남) |
| 오른쪽 `단서 노트` | 지금까지 본 글 |

장소가 바뀌면 연출이 나옵니다. 문을 열고 이동하면 문이 갈라지고, 그 밖의 이동은 스캔라인과 장소 이름 카드가 뜹니다.
소리는 오른쪽 위 🔊 버튼으로 끌 수 있고, OS의 "동작 줄이기" 설정이 켜져 있으면 연출 없이 바로 바뀝니다.

## 설정 (환경변수, 모두 선택)

`.env`에 적거나 셸에 설정합니다.

| 이름 | 기본값 | 설명 |
|---|---|---|
| `OPENAI_API_KEY` | (필수) | OpenAI 키 |
| `OPENAI_MODEL` | `gpt-4o-mini` | 사용할 모델 |
| `GAME_URL` | 강사 게임 서버 | 게임 서버(MCP) 주소 |
| `PORT` | `8765` | 웹 버전 포트 |
| `NO_BROWSER` | (없음) | 값이 있으면 웹 서버가 브라우저를 자동으로 열지 않음 |
| `NO_RICH` | (없음) | 값이 있으면 터미널 색상·패널 없이 일반 출력 |
| `NO_ANIM` | (없음) | 값이 있으면 터미널 문 열림 애니메이션 끔 |

## 문제 해결

| 증상 | 해결 |
|---|---|
| `OPENAI_API_KEY가 없습니다` | `.env`를 만들고 키를 채웠는지 확인 |
| `Failed building wheel for pyyaml` | Python 3.12 가상환경을 쓰세요 (위 "시작하기" 참고) |
| 웹 화면이 깨지고 `scenes.js를 불러오지 못했습니다` | `web_server.py`를 Ctrl+C로 끄고 다시 실행 |
| 코드를 고쳤는데 그대로임 | `my_tools.py`와 `web/` 파일은 저장/새로고침(Ctrl+F5)이면 됩니다. 그 밖의 `.py`를 고쳤다면 서버를 다시 실행하세요 |
| 서버실 등에 문이나 물체가 안 보임 | 오른쪽 `이 장소에서`의 `⚠ 읽지 못한 줄`을 확인하세요. 서버 응답 형식을 못 읽은 것입니다 |
| 다른 화면이 뜨거나 이상한 오류 | 이미 떠 있는 옛 서버가 같은 포트를 쓰고 있을 수 있습니다. 옛 서버를 끄고 다시 실행 |
| 힌트가 안 나옴 | 메시지에 "힌트"가 들어가야 합니다 (규칙 참고) |

## 개발자용: 파일 구성

| 파일 | 역할 |
|---|---|
| `client.py` | 터미널 버전 진입점, 시스템 프롬프트(`RULES`) |
| `web_server.py`, `web/` | 웹 버전. `web/index.html`이 화면, `web/scenes.js`가 장면 그림 |
| `engine.py` | 게임 루프와 규칙 검문 (웹·터미널 공용) |
| `guards.py` | 힌트·정답·이동 판단 규칙 |
| `game_server.py`, `mcp_http.py` | 게임 서버(MCP)를 직접 호출. 세션을 자동으로 붙임 |
| `hot_tools.py` | `my_tools.py` 저장 시 실시간 반영 |
| `ui.py` | 터미널 화면과 서버 응답(장소 박스) 해석 |
| `my_tools.py` | **여러분이 작성하는 파일** |
